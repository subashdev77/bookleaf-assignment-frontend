# BookLeaf Support Portal: Frontend

Next.js 16 (App Router) + Tailwind CSS 4 client for the Author and Admin portals.
See the [root README](../README.md) for setup, architecture and deployment.

```bash
cp .env.example .env.local   # then adjust if the API isn't on localhost:5000
npm install
npm run dev                  # http://localhost:3000
```
